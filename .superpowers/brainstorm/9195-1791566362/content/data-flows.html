Bagian 2 — Alur data utama

Tiga alur inti produk. Perhatikan titik keputusan (belah ketupat) dan aksi berisiko tinggi yang wajib konfirmasi.

Alur 1 — Onboarding / Connect
1️⃣ User klik add-on di Accurate Store
▼
2️⃣ Accurate buka /launch kita
membawa code/token + id data usaha
▼
3️⃣ Kita tukar → access + refresh token
open-db → session & host tersimpan
▼
◆ Sudah punya akun?
ya → login  |  tidak → buat akun (Admin pertama)
4️⃣ Connect Google Drive (OAuth terpisah)
▼
5️⃣ Selesai → langsung ke Chat/Explore
Akun pertama otomatis dapat role default Admin
Alur 2 — Chat / Voice ke data akuntansi
1️⃣ User ketik / tekan mic
▼
2️⃣ STT: audio → teks
(Gemini native audio / Web Speech — sesuai setting admin)
▼
3️⃣ Gemini tool loop: model panggil tool
→ cek permission role → adapter → API provider
(boleh multi-langkah: ambil → hitung → ambil lagi)
▼
4️⃣ Jawaban: teks + tabel angka
+ TTS → audio (kalau mode voice)
▼
5️⃣ Tersimpan di riwayat chat (per tenant)
⛔ Tool ditolak jika role tidak punya
hak akses modul terkait → AI menjawab
"Anda tidak punya akses modul X"
Alur 3 — Rapikan Drive (tombol, bukan chat)
1️⃣ User buka Explore Manager,
pilih folder kerja (poin spek #4)
▼
2️⃣ Klik tombol "Rapikan Folder Ini"
▼
3️⃣ Scan isi → ambil PDF → Gemini Vision
baca isi dokumen → klasifikasi jenis
▼
4️⃣ Rencana aksi ditampilkan dulu:
folder apa yang dibuat, file apa yang
rename & pindah (preview daftar)
◆ User klik "Jalankan" (consent)
5️⃣ Eksekusi: create folder → rename → move
progres per file, bisa dibatalkan
6️⃣ Laporan hasil + log undo info
(posisi asal tiap file tercatat)
